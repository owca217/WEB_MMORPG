# Nearby and global chat

Add a chat icon outside the collapsible HUD in both world and battle scenes, shared by web and Android. The window has nearby/global tabs and bounded in-memory transcripts. Global chat reaches every authenticated player across locations and battles; recent global history is loaded on entry. Nearby chat is live only: a recipient sees messages from speakers inside their visible camera rectangle, derived from authoritative world positions and bounded camera dimensions. Nearby is unavailable during the current single-player battles.

The server supplies identity, timestamps and positions. Accept plain trimmed text up to300 UTF16 characters, with per-character flood limits. Do not replay nearby history to newcomers. A speech bubble follows the sender's world sprite and expires automatically. Client transcript de-duplicates socket events, acknowledgements and history, stays bounded, and clears when changing session.

Typing disables movement and releases Phaser keyboard capture, including WASD and arrows. Closing chat restores control. Mobile layout keeps the composer visible when the soft keyboard changes the visual viewport; Android Back closes the panel. Preserve drafts on errors and avoid duplicate pending sends.

- Shared contract/server routing and focused auth/range/rate tests.
- ChatWidget tabs, unread states, safe rendering, ACK handling and mobile viewport layout.
- Moving/expiring speech bubbles in world renderer.
- Client store/socket/controller and scene lifecycle integration.
- Desktop + phone-size browser QA with two local test accounts, focused regression checks, review, deployment and signed Android0.1.4.
